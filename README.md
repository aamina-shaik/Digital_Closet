<h2 style="font-family:Binggrae, sans-serif;">✨ About The Project</h2>

<strong>Your Closet</strong> is a clean and elegant wardrobe management web application where users can:

<ul>
<li>Upload clothing items with images</li>
<li>Organize outfits by categories</li>
<li>Search and filter wardrobe items</li>
<li>Generate random outfit combinations</li>
<li>Save favorite outfits locally</li>
</ul>

<p>
The project focuses on creating a smooth and visually aesthetic user experience with soft neutral tones, elegant typography, and responsive layouts.
</p>


<h2 style="font-family:Binggrae, sans-serif;">🛠 Tech Stack</h2>

<ul>
<li><strong>HTML5</strong> — structure and layout</li>
<li><strong>CSS3</strong> — styling, animations, responsive design</li>
<li><strong>JavaScript</strong> — interactivity and outfit generation logic</li>
<li><strong>LocalStorage API</strong> — persistent wardrobe data storage</li>
<li><strong>Google Fonts</strong> — typography styling</li>
</ul>
